# Experiment 01 — PawVault / Private Pet Photo Search

Status: **Completed — findings captured**

PawVault was the first QVAC Vision Lab experiment. It tested whether small local vision models could turn private, real-world pet photos into reliable searchable attributes. The complete interactive workspace, historical run data, prompts, reviews, failures, runtime traces, and exports remain available in the main app.
